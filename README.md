# SKH OR schedule

Live: https://skh-or-schedule.vercel.app

การใช้ห้องผ่าตัดหลัก 13 ห้อง ปีงบประมาณ 2569 (1 ต.ค. 2568 – 30 ก.ย. 2569)
ตารางเทียบทุกห้องแยกตามช่วงเวลาและวันในสัปดาห์ แผนผังแยกตามช่วงเวลา (ในเวลาราชการ เวรบ่าย เวรดึก) และตามวัน ชี้หรือแตะที่ห้องเพื่อดูสัดส่วนสาขาที่ใช้ห้องนั้น

Utilization of the 13 main operating rooms in fiscal year 2569, by time band and by weekday, with each room's share by surgical department. Built from the finalized FY2569 case list (18,303 timed cases in rooms 1-13).

- `index.html` is a single static page (data embedded, no build step). Open it directly or serve the folder.
- `og.png` is the link preview image.

Figures are aggregates only; no patient-level data is included.
